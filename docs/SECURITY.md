# Security

## What is supported

The site as it runs now, and the latest commit on `main`. Older commits get no fixes;
anyone running their own copy should keep it up to date.

## Reporting a problem

Please don't open a public issue. Email andria24b@gmail.com with "Security" in the
subject, saying:

- what the problem is, and where (the page, the address, or the file and line)
- how to make it happen, step by step
- what someone could do with it

You'll get an answer within a week. Once it's fixed, you'll be credited in the fix's
commit if you'd like to be.

## What counts

Anything that lets someone read, change or delete what isn't theirs: another visitor's
conversion or PDF, the admin, messages and suggestions people sent, or the server's
files. Also ways around the upload checks or the limit on how often one visitor may post.

Not counted: floods of traffic, reports from automated scanners with no way shown to use
them, and problems in PDF2EPUB itself, which go to
[its own security policy](https://github.com/andriaberi/PDF2EPUB/blob/main/docs/SECURITY.md).
